# Проверяемые расширения физических моделей

Модуль `QCLNEGF.PhysicalModelExtensions` содержит самостоятельные операторы с
размерными входами. Все физические параметры входят в `model_identity`; температура,
непараболичность и время жизни фононов не выбираются по невязке или току. Конструкторы,
включая позиционные, проверяют размеры и допустимость параметров.

Здесь разграничены готовый оператор и его включение в транспорт. Успешный
аналитический тест оператора сам по себе не подтверждает новый вариант расчёта
тока или усиления ККЛ. Расширения включаются явным выбором модели.

| Модель | Реализованный контракт | Граница применения |
|---|---|---|
| Фиксированное экранирование | Явные κ, εᵣ и размерность 2/3 | Число κ само по себе не определяет форму взаимодействия |
| Трёхмерное экранирование Дебая | κ(n₃ᴅ,T) и трёхмерный потенциал | Классический однородный электронный газ |
| Двумерное экранирование Томаса–Ферми | Конечная T, κ(n₂ᴅ,T,m,g), двумерный потенциал | Длинноволновой предел одного параболического поддиапазона |
| Модель Кейна | Дисперсия, скорость, плотность состояний, интегральные веса и однородный кинетический оператор | Не рецепт для произвольного гетероперехода |
| Баланс населённости LO | N, испускание и поглощение, стационарное и временное замыкание, энергетический баланс | Электронные коэффициенты заданы на текущем шаге |
| Электронные столкновения с учётом принципа Паули | Обратимые бинарные столкновения с сохранением числа, энергии и импульса | Квазичастичное кинетическое приближение |
| Одноплазмонное приближение для взаимодействия электронов (SPPA) | Полная матрица подзонных взаимодействий, динамические Σˡ/Σᵍ/Σᴿ и вклад Фока | Представительное q и заданная электронная температура плазмонов. Сохранение энергии проверяют отдельно |
| Оптическая мощность | Работа оптического поля из комплексной χ | Линейный отклик при отсутствии насыщения и обратной связи резонатора |

## Размерность экранирования

В соглашении обратного преобразования Фурье $\int d^dq/(2\pi)^d$ реализованы

```math
V_{2D}(q)=\frac{e^2}{2\epsilon_0\epsilon_r(q+\kappa_{2D})},\qquad
V_{3D}(q)=\frac{e^2}{\epsilon_0\epsilon_r(q^2+\kappa_{3D}^2)}.
```

Единицы — J·m² и J·m³ соответственно. Площадь нормировки и межподзонные
формфакторы в эти функции не входят. Подстановка двумерного κ в трёхмерный
знаменатель не воспроизводит двумерное экранирование.

Для классического газа $\kappa_{3D}^2=e^2n_{3D}/(\epsilon_0\epsilon_r k_BT)$.
Для идеального двумерного газа $D_0=gm/(2\pi\hbar^2)$ и

```math
\kappa_{2D}=\frac{e^2D_0}{2\epsilon_0\epsilon_r}
\left[1-\exp\left(-\frac{n_{2D}}{D_0 k_BT}\right)\right].
```

Это следует из $n=D_0k_BT\ln(1+\exp(\mu/k_BT))$ и термодинамической
производной $\partial n/\partial\mu$. Выражения соответствуют формулам после
(9) в [Winge et al. (2016), §2.1–2.3](https://arxiv.org/html/1602.03997).
Длинноволновое двумерное приближение связано с
[Stern (1967)](https://doi.org/10.1103/PhysRevLett.18.546);
конечные q, динамика, несколько поддиапазонов и вырожденный 3D газ требуют иных
поляризационных операторов. Модель Дебая здесь ограничена классическим газом.

## Непараболичность: одна дисперсия для всех мер

Выбрана однородная изотропная проводящая зона с явно заданными $m>0$, $\alpha\ge0$:

```math
E(1+\alpha E)=E_p=\frac{\hbar^2k^2}{2m},\qquad
E=\frac{2E_p}{1+\sqrt{1+4\alpha E_p}},\qquad
v(k)=\frac{\hbar k}{m(1+2\alpha E)}.
```

Дисперсия Кейна и транспортная масса проверены по
[Whalley et al. (2019), (5)–(6)](https://arxiv.org/html/1811.02281),
исходная работа — [Kane (1957)](https://doi.org/10.1016/0022-3697(57)90013-6).
Материальные значения α из другой структуры автоматически не переносятся.

Подсчёт состояний в круге k-пространства даёт

```math
\mathcal N_{2D}(E)=\frac{gk^2(E)}{4\pi}
=\frac{gm}{2\pi\hbar^2}E(1+\alpha E),\qquad
D_{2D}(E)=\frac{gm}{2\pi\hbar^2}(1+2\alpha E).
```

`kane_energy_bin_weights_2d` использует разности $\mathcal N$ на границах ячеек.
При интегрировании непосредственно по k мера $k\,dk/(2\pi)$ сохраняется;
домножать её ещё раз на изменённую плотность состояний нельзя. `kane_kinetic_operator`
применяет ту же функцию к спектру положительного эрмитова T. Он не преобразует
весь $T+V$ и не задаёт граничные условия разрывных m(z), α(z). Для такого
гетероструктурного расширения требуется отдельный вывод гамильтониана и операторов.

Интегрированный вариант `physical_models.dispersion: kane_inplane` делает
более узкое изменение: применяет этот корень только к локальной поперечной
кинетической энергии $\hbar^2k_\parallel^2/[2m_\parallel(z)]$ до проекции в
базис. Продольная кинетика и квантовое ограничение по-прежнему описываются
параболическим оператором БенДэниела—Дьюка (BDD). Полученная матрица входит во
все гамильтонианы, а плотности интегрируются по исходной мере k. Эта модель
ограничена непараболичностью поперечной дисперсии.

## Неравновесные LO-фононы

За основу принят член релаксации со временем τ из фононного уравнения
[Shi & Knezevic (2016), (1b) и §II](https://arxiv.org/html/1607.07943).
Населённость N относится к одной фононной моде или явно заданной однородной
группе мод. Электронные коэффициенты a,b имеют единицы с⁻¹
и не включают бозонные множители:

```math
\dot N=a(N+1)-bN-\frac{N-N_B(T_L)}{\tau},\qquad
N_* = \frac{a+N_B/\tau}{b+1/\tau-a}.
```

Стационарное решение разрешено при $b+1/\tau-a>0$; иначе выдаётся явная ошибка
отсутствия устойчивого конечного решения при фиксированных электронных коэффициентах переходов.
Временной шаг вычисляется аналитически для постоянных a,b. Функция
`lo_scattering_factors` возвращает $N+1$ для испускания и N для поглощения.

Баланс для одной моды записан непосредственно из того же уравнения:

```math
P_{e\to LO}=\hbar\omega_{LO}[a(N+1)-bN],\qquad
P_{LO\to bath}=\hbar\omega_{LO}(N-N_B)/\tau,\qquad
\dot U_{LO}=P_{e\to LO}-P_{LO\to bath}.
```

Функция `lo_population_temperature` вычисляет эквивалентную температуру распределения Бозе
однородного N. В расчёте переноса параметр `Tᴸᴼ` уже отличается от
`Tᴸ` и определяет множители LO в обеих реализациях решателя. Это позволяет исследовать
заданную фононную температуру. Интегрированный `lo_population: rate_balance`
получает a,b из собственных энергий исходящих процессов испускания и поглощения
и того же Gˡ, затем вычисляет N для каждого кандидата SCBA. Плотность мод
`lo_mode_density_per_m3` и время `lo_decay_ps` обязательны: без них нельзя
превратить число электронных переходов на площадь в изменение населённости одной моды. Этот вариант замыкает однородное
стационарное уравнение баланса. Зависимость от q требует отдельного
фононного уравнения Больцмана.

## Сохраняющий кинетический оператор электронных столкновений

Используется марковское приближение с энергиями на массовой поверхности.
Населённости $0\le f_i\le1$ относятся к отдельным спиновым состояниям
с одинаковым фазовым весом. Для одного канала $1+2\leftrightarrow3+4$

```math
R=\gamma[f_1f_2(1-f_3)(1-f_4)-f_3f_4(1-f_1)(1-f_2)],\qquad
\dot{\boldsymbol f}=R(-1,-1,1,1).
```

Квантовая статистическая структура следует из
[Uehling & Uhlenbeck (1933)](https://doi.org/10.1103/PhysRev.43.552).
Каждый канал проверяется на $E_1+E_2=E_3+E_4$ и
$\mathbf k_1+\mathbf k_2=\mathbf k_3+\mathbf k_4$ с явными допусками.
Именованные `DEFAULT_BINARY_ENERGY_CONSERVATION_ATOL = 10⁻¹² eV` и
`DEFAULT_BINARY_MOMENTUM_CONSERVATION_ATOL = 10⁻⁴ m⁻¹` задают абсолютные
пороги проверки входных дискретных состояний, а не параметры материала или
ширину столкновения. Пользователь может задать другой допуск, в том числе
ноль; оба значения входят в идентификатор модели. Энергии и импульсы не исправляются.
Прямой и обратный канал нельзя записать дважды. Тождества моментов следуют из
вектора стехиометрии и проверяются прямыми независимыми проекциями в тесте.
Распределение Ферми обращает R в нуль благодаря сохранению энергии.

Пользователь задаёт неотрицательные коэффициенты γ и указывает их
происхождение. Экранированное кулоновское взаимодействие, обмен и нормировка
конечных состояний входят в обоснование этих коэффициентов. Кинетический
оператор описывает сохраняющие столкновения. Вклады Хартри и обменный сдвиг
энергии в него не входят. Неравные квадратурные веса, когерентности и
уширение вне массовой поверхности требуют отдельного расширения. Для этого
оператора не установлена применимость к сравнению тока, распределений
или усиления ККЛ. Интегрированное расширение ниже задаёт собственную энергию
электронного рассеяния для SCBA.

## Одноплазмонное приближение в SCBA

`ElectronElectronOptions(mode=:sppa_single_q, ...)` включает представительное
$q_*>0$ в одноплазмонной схеме [Winge et al., (5)–(20)](https://arxiv.org/html/1602.03997).
Отключённый режим `mode=:none` хранит `nothing` для физических параметров;
фиктивных температуры, плотности, массы или волнового числа в нём нет.
Размерность экранирования и параметры n, $T_e$, m и $q_*$ обязательны. Введены

```math
E_{pl,2D}^2=\frac{\hbar^2e^2n_{2D}q_*}{2\epsilon_0\epsilon_rm},\qquad
E_{pl,3D}^2=\frac{\hbar^2e^2n_{3D}}{\epsilon_0\epsilon_rm},
```

```math
E_p^2=E_{pl}^2(1+s)+\left(\frac{\hbar^2q_*^2}{2m}\right)^2,
\quad s_{2D}=q_*/\kappa,\quad s_{3D}=q_*^2/\kappa^2,
\quad K_{acdb}=V_{acdb}(q_*)\frac{E_{pl}^2}{2E_p}.
```

Сохраняется полный подзонный формфактор
$F_{acdb}=\int dz\,dz'\,\chi_a^*\chi_c(z)e^{-q_*|z-z'|}\chi_d^*\chi_b(z')$.
Меньшая и большая компоненты содержат сдвиги $E\pm E_p$ и множители
$N_p,N_p+1$, где $N_p=N_B(E_p,T_e)$. Запаздывающая часть использует выбранное
преобразование Гильберта. Вклад Фока добавляется отдельно в Σᴿ. Поле Хартри
учитывается один раз.

Представительное q заменяет зависимость от угла и переноса импульса, поэтому
точное сохранение импульса полного GW здесь не заявлено. Фиксированное $T_e$
плазмонов также не гарантирует нулевой обмен электронной энергией. Численный
контроль `r_energy_electron_electron` и зарядовый баланс входят в итоговую
валидацию; малость невязки неподвижной точки не отменяет эти проверки. Отключение
вклада Фока (`include_exchange: false`) — отдельная объявленная аппроксимация.

Код `numerics/optimized/electron_electron.jl` собирает настоящий элемент
`KernelSet[:electron_electron]`, а эталонная и оптимизированная реализации SCBA включают его
`SelfEnergyFamily` в общий кандидат. Совпадение реализаций проверяет подключение
общей свёртки. Независимые тесты проверяют полюс, квадратуру формфактора,
положительность, знак вклада Фока, причинность и зарядовое тождество
при сопряжённых переносах.

## Оптическая работа и применимость χ

При $E(t)=\operatorname{Re}[E_0e^{-i\omega t}]$ и
$P(t)=\operatorname{Re}[\epsilon_0\chi E_0e^{-i\omega t}]$ усреднение
$E\dot P$ даёт

```math
\overline p=\frac{\epsilon_0\omega}{2}\operatorname{Im}\chi\,|E_0|^2.
```

`optical_power_density` возвращает Вт/м³, принимает пиковую амплитуду поля,
различает поглощение ($\overline p>0$) и вынужденное излучение
($\overline p<0$). Отдельно проверяются RMS-нормировка и квадрат по полю.

Функция `bare_bubble_optical_response` вычисляет отклик в калибровке длины
при фиксированной собственной энергии $\delta\Sigma=0$ без вершинных поправок. Их учёт
в полной теории обсуждается в
[Pereira, Lee & Wacker (2004), (1)–(4)](https://arxiv.org/html/cond-mat/0404015).
Энергетическая диагностика сохраняет исходные населённости. Ток в режиме
генерации требует модели связи с полем, потерь в резонаторе и насыщения.

## Запуск проверки и состояние интеграции

```julia
using QCLNEGF, Unitful
const Models = QCLNEGF.PhysicalModelExtensions
bath = Models.HotLOPhononBath(36.7u"meV", 70u"K", 5u"ps")
# Коэффициенты переходов выбраны для демонстрации.
population = Models.steady_lo_population(bath, 1e11u"s^-1", 2e11u"s^-1")
Models.lo_energy_balance(bath, population, 1e11u"s^-1", 2e11u"s^-1")
```

Тест `test/numerics/test_model_extensions.jl` проверяет классический и
вырожденный пределы экранирования, параболический предел, число плосковолновых
состояний, производную дисперсии, детальное равновесие, инварианты столкновений
и оптическую мощность. Температурные пределы проверяют аналитические формулы, а
исследовательский пример использует 70 K.

Конфигурационные поля находятся в корневом разделе `physical_models`.
Прочие поля сохраняют базовые значения.

| Вопрос | Поля |
|---|---|
| Экранирование | `screening: density_temperature`, `screening_temperature_K`, `screening_mass_ratio` |
| Поперечная дисперсия Кейна | `dispersion: kane_inplane`, `nonparabolicity_per_eV` |
| Заданное N_LO | `lo_population: fixed_occupation`, `lo_fixed_occupation` |
| Баланс населённости LO | `lo_population: rate_balance`, `lo_decay_ps`, `lo_mode_density_per_m3` |
| Одноплазмонное приближение | `electron_electron` с полями примера ниже |

Для `density_temperature` используется заданная поверхностная плотность ионизованных доноров.
Объёмная плотность равна ей, делённой на длину периода. Для примесей
используется двумерное κ, для LO — трёхмерное κ. Это термодинамическая оценка
экранирования по заданной плотности.

Пример параметров для исследовательского запуска. Для конкретного прибора
они требуют физического обоснования.

```yaml
physical_models:
  electron_electron:
    mode: sppa_single_q
    screening_dimension: 2
    transfer_wavenumber_per_nm: 0.1
    electron_temperature_K: 70
    effective_mass_ratio: 0.067
    carrier_density_per_m2: 4.5e14
    include_exchange: true
```

При `screening_dimension: 3` обязательно `carrier_density_per_m3` вместо
`carrier_density_per_m2`. Численные значения q, α, τ и плотности мод требуют отдельного обоснования.
Реализацию операторов, сходимость и сопоставление принятых значений тока,
распределений и усиления проверяют раздельно.
