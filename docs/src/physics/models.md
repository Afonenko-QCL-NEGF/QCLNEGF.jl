# Проверяемые расширения физических моделей

Модуль `QCLNEGF.PhysicalModelExtensions` содержит самостоятельные операторы с
размерными входами. Все физические параметры входят в `model_identity`; температура,
непараболичность и время жизни фононов не выбираются по невязке или току. Конструкторы,
включая позиционные, проверяют размеры и допустимость параметров.

Здесь разграничены готовый оператор и его включение в транспорт. Успешный
аналитический тест оператора сам по себе не подтверждает новый вариант расчёта
тока или усиления QCL. Baseline не включает перечисленные расширения автоматически.

| Модель | Реализованный контракт | Граница применения |
|---|---|---|
| Fixed screening | Явные κ, εᵣ и размерность 2/3 | Число κ само по себе не определяет форму взаимодействия |
| Debye 3D | κ(n₃ᴅ,T) и трёхмерный потенциал | Классический однородный электронный газ |
| Thomas–Fermi 2D | Конечная T, κ(n₂ᴅ,T,m,g), двумерный потенциал | Длинноволновой предел одного параболического поддиапазона |
| Kane | Dispersion, скорость, DOS, интегральные веса и однородный кинетический оператор | Не рецепт для произвольного гетероперехода |
| LO rate balance | N, emission/absorption, стационарное и временное замыкание, энергетический баланс | Электронные коэффициенты заданы на текущем шаге |
| e–e Pauli | Обратимые бинарные столкновения с сохранением числа, энергии и импульса | Квазичастичное кинетическое приближение, не NEGF self-energy |
| e–e SPPA | Полная матрица подзонных взаимодействий, dynamic Σˡ/Σᵍ/Σᴿ и Fock | Представительное q, заданная электронная температура плазмонов; energy leakage проверяется отдельно |
| Optical power | Работа оптического поля из комплексной χ | Диагностика линейного отклика без saturation/cavity feedback |

## Screening: размерность является частью модели

В соглашении обратного преобразования Фурье $\int d^dq/(2\pi)^d$ реализованы

```math
V_{2D}(q)=\frac{e^2}{2\epsilon_0\epsilon_r(q+\kappa_{2D})},\qquad
V_{3D}(q)=\frac{e^2}{\epsilon_0\epsilon_r(q^2+\kappa_{3D}^2)}.
```

Единицы — J·m² и J·m³ соответственно. Площадь нормировки и межподзонные
формфакторы в эти функции не входят. Подстановка двумерного κ в трёхмерный
знаменатель не считается реализацией двумерного screening.

Для классического газа $\kappa_{3D}^2=e^2n_{3D}/(\epsilon_0\epsilon_r k_BT)$.
Для идеального двумерного газа $D_0=gm/(2\pi\hbar^2)$ и

```math
\kappa_{2D}=\frac{e^2D_0}{2\epsilon_0\epsilon_r}
\left[1-\exp\left(-\frac{n_{2D}}{D_0 k_BT}\right)\right].
```

Это следует из $n=D_0k_BT\ln(1+\exp(\mu/k_BT))$ и термодинамической
производной $\partial n/\partial\mu$. Выражения соответствуют формулам после
(9) в [Winge et al. (2016), §2.1–2.3](https://arxiv.org/html/1602.03997).
Длинноволновое двумерное приближение связано с
[Stern (1967)](https://doi.org/10.1103/PhysRevLett.18.546);
конечные q, динамика, несколько поддиапазонов и вырожденный 3D газ требуют иных
поляризационных операторов. Debye не объявляется пригодным для вырожденного газа.

## Непараболичность: одна дисперсия для всех мер

Выбрана однородная изотропная проводящая зона с явно заданными $m>0$, $\alpha\ge0$:

```math
E(1+\alpha E)=E_p=\frac{\hbar^2k^2}{2m},\qquad
E=\frac{2E_p}{1+\sqrt{1+4\alpha E_p}},\qquad
v(k)=\frac{\hbar k}{m(1+2\alpha E)}.
```

Форма Kane и транспортная масса проверены по
[Whalley et al. (2019), (5)–(6)](https://arxiv.org/html/1811.02281),
исходная работа — [Kane (1957)](https://doi.org/10.1016/0022-3697(57)90013-6).
Материальные значения α из другой структуры автоматически не переносятся.

Подсчёт состояний в круге k-пространства даёт

```math
\mathcal N_{2D}(E)=\frac{gk^2(E)}{4\pi}
=\frac{gm}{2\pi\hbar^2}E(1+\alpha E),\qquad
D_{2D}(E)=\frac{gm}{2\pi\hbar^2}(1+2\alpha E).
```

`kane_energy_bin_weights_2d` использует разности $\mathcal N$ на границах ячеек.
При интегрировании непосредственно по k мера $k\,dk/(2\pi)$ сохраняется;
домножать её ещё раз на изменённую DOS нельзя. `kane_kinetic_operator`
применяет ту же функцию к спектру положительного эрмитова T. Он не преобразует
весь $T+V$ и не задаёт граничные условия разрывных m(z), α(z). Для такого
гетероструктурного расширения требуется отдельный вывод Hamiltonian и операторов.

Интегрированный вариант `physical_models.dispersion: kane_inplane` делает
более узкое изменение: применяет этот корень только к локальной поперечной
кинетической энергии $\hbar^2k_\parallel^2/[2m_\parallel(z)]$ до проекции в
базис. Продольный оператор BDD и confinement остаются параболическими по
определению данной модели. Во всех Hamiltonian используется полученная
матрица; плотности интегрируются по исходной k-мере. Этот вариант не
объявляется полной многозонной непараболичностью гетероструктуры.

## Неравновесные LO-фононы

За основу принят relaxation-time член фононного уравнения
[Shi & Knezevic (2016), (1b) и §II](https://arxiv.org/html/1607.07943).
В данном модуле одна occupation N представляет один фононный мод или явно
объявленную однородную группу мод. Электронные коэффициенты a,b имеют единицы s⁻¹
и не включают бозонные множители:

```math
\dot N=a(N+1)-bN-\frac{N-N_B(T_L)}{\tau},\qquad
N_* = \frac{a+N_B/\tau}{b+1/\tau-a}.
```

Стационарное решение разрешено при $b+1/\tau-a>0$; иначе выдаётся явная ошибка
отсутствия устойчивого конечного решения при замороженных электронных rates.
Временной шаг вычисляется аналитически для постоянных a,b. Функция
`lo_scattering_factors` возвращает $N+1$ для emission и N для absorption.

Баланс на один мод записан непосредственно из того же уравнения:

```math
P_{e\to LO}=\hbar\omega_{LO}[a(N+1)-bN],\qquad
P_{LO\to bath}=\hbar\omega_{LO}(N-N_B)/\tau,\qquad
\dot U_{LO}=P_{e\to LO}-P_{LO\to bath}.
```

Функция `lo_population_temperature` вычисляет эквивалентную Bose-температуру
однородного N. В существующем transport физический `Tᴸᴼ` уже отличается от
`Tᴸ` и определяет LO-множители в обоих solver; это позволяет явно исследовать
заданную фононную температуру. Интегрированный `lo_population: rate_balance`
получает a,b из исходящих emission/absorption self-energies и того же Gˡ,
затем вычисляет N в каждом SCBA candidate. Плотность участвующих мод
`lo_mode_density_per_m3` и время `lo_decay_ps` обязательны: без них нельзя
превратить число электронных переходов на площадь в изменение N одного мода.
Это самосогласованное однородное стационарное rate closure; q-зависимая
фононная Boltzmann-задача остаётся отдельной моделью.

## e–e: сохраняющий кинетический контрольный оператор

Выбрано on-shell Markov-приближение для occupation $0\le f_i\le1$ отдельных
spin-resolved состояний одинакового фазового веса. Для одного канала $1+2\leftrightarrow3+4$

```math
R=\gamma[f_1f_2(1-f_3)(1-f_4)-f_3f_4(1-f_1)(1-f_2)],\qquad
\dot{\boldsymbol f}=R(-1,-1,1,1).
```

Квантовая статистическая структура следует из
[Uehling & Uhlenbeck (1933)](https://doi.org/10.1103/PhysRev.43.552).
Каждый канал проверяется на $E_1+E_2=E_3+E_4$ и
$\mathbf k_1+\mathbf k_2=\mathbf k_3+\mathbf k_4$ с явными допусками.
Именованные `DEFAULT_BINARY_ENERGY_CONSERVATION_ATOL = 10⁻¹² eV` и
`DEFAULT_BINARY_MOMENTUM_CONSERVATION_ATOL = 10⁻⁴ m⁻¹` задают абсолютные
пороги проверки входных дискретных состояний, а не параметры материала или
ширину столкновения. Пользователь может задать другой допуск, в том числе
ноль; оба значения входят в identity модели. Энергии и импульсы не исправляются.
Прямой и обратный канал нельзя записать дважды. Тождества моментов следуют из
вектора стехиометрии и проверяются прямыми независимыми проекциями в тесте.
Fermi-распределение зануляет R благодаря сохранению энергии.

Пользователь обязан задать неотрицательные коэффициенты γ и их происхождение;
матрицы экранированного Coulomb, exchange и нормировка конечных состояний не
выдумываются. Оператор не добавляет Hartree или exchange energy shift,
не разрешает искусственную потерю энергии и не заменяет отсутствующую e–e
self-energy в SCBA. Неравные quadrature weights, когерентности и off-shell
ширины требуют отдельного адаптера. Отсутствуют основанные на этом операторе
подтверждённые сравнения J/distribution/gain QCL для этого Pauli API;
интегрированное e–e расширение ниже использует другой, явно названный оператор.

## e–e SPPA в SCBA

`ElectronElectronOptions(mode=:sppa_single_q, ...)` включает представительное
$q_*>0$ в single-plasmon-pole схеме [Winge et al., (5)–(20)](https://arxiv.org/html/1602.03997).
Отключённый режим `mode=:none` хранит `nothing` для физических параметров;
фиктивных температуры, плотности, массы или волнового числа в нём нет.
Параметры screening dimension, n, $T_e$, m и $q_*$ обязательны. Введены

```math
E_{pl,2D}^2=\frac{\hbar^2e^2n_{2D}q_*}{2\epsilon_0\epsilon_rm},\qquad
E_{pl,3D}^2=\frac{\hbar^2e^2n_{3D}}{\epsilon_0\epsilon_rm},
```

```math
E_p^2=E_{pl}^2(1+s)+\left(\frac{\hbar^2q_*^2}{2m}\right)^2,
\quad s_{2D}=q_*/\kappa,\quad s_{3D}=q_*^2/\kappa^2,
\quad K_{acdb}=V_{acdb}(q_*)\frac{E_{pl}^2}{2E_p}.
```

Сохраняется полный подзонный формфактор
$F_{acdb}=\int dz\,dz'\,\chi_a^*\chi_c(z)e^{-q_*|z-z'|}\chi_d^*\chi_b(z')$.
Lesser/greater содержат сдвиги $E\pm E_p$ и множители $N_p,N_p+1$,
$N_p=N_B(E_p,T_e)$. Retarded часть использует выбранное Hilbert-преобразование.
Bare Fock добавляется отдельно в Σᴿ; Hartree повторно не добавляется.

Представительное q заменяет зависимость от угла и переноса импульса, поэтому
точное сохранение импульса полного GW здесь не заявлено. Фиксированное $T_e$
плазмонов также не гарантирует нулевой обмен электронной энергией. Численный
контроль `r_energy_electron_electron` и зарядовый баланс входят в итоговую
валидацию; малый fixed-point residual не перекрывает их отказ. Отключение
Fock (`include_exchange: false`) — отдельная объявленная аппроксимация.

Код `numerics/optimized/electron_electron.jl` собирает настоящий элемент
`KernelSet[:electron_electron]`, а reference и production SCBA включают его
`SelfEnergyFamily` в общий candidate. Общая физическая contraction означает,
что совпадение двух входов проверяет wiring, а не служит независимым oracle.
Независимые tests проверяют полюс, quadrature формфактора, положительность,
Fock sign, причинность и зарядовое тождество при сопряжённом remap.

## Оптическая работа и применимость χ

При $E(t)=\operatorname{Re}[E_0e^{-i\omega t}]$ и
$P(t)=\operatorname{Re}[\epsilon_0\chi E_0e^{-i\omega t}]$ усреднение
$E\dot P$ даёт

```math
\overline p=\frac{\epsilon_0\omega}{2}\operatorname{Im}\chi\,|E_0|^2.
```

`optical_power_density` возвращает W/m³, принимает пиковую амплитуду поля,
различает absorption ($\overline p>0$) и stimulated emission
($\overline p<0$). Отдельно проверяются RMS-нормировка и квадрат по полю.

Текущий `bare_bubble_optical_response` — length-gauge отклик при фиксированной
self-energy, $\delta\Sigma=0$, без vertex corrections. Наличие таких поправок
в полной теории обсуждается в
[Pereira, Lee & Wacker (2004), (1)–(4)](https://arxiv.org/html/cond-mat/0404015).
Настоящий энергетический diagnostic не обновляет populations. Ни χ,
ни нулеполевой transport не определяют ток в режиме генерации без модели связи
с полем, cavity losses и насыщением.

## Запуск проверки и состояние интеграции

```julia
using QCLNEGF, Unitful
const Models = QCLNEGF.PhysicalModelExtensions
bath = Models.HotLOPhononBath(36.7u"meV", 70u"K", 5u"ps")
# Иллюстративные rates, а не результат QCL или материальный fit:
population = Models.steady_lo_population(bath, 1e11u"s^-1", 2e11u"s^-1")
Models.lo_energy_balance(bath, population, 1e11u"s^-1", 2e11u"s^-1")
```

Тест `test/numerics/test_model_extensions.jl` проверяет классический и
вырожденный screening-пределы, параболический предел, число plane-wave states,
производную dispersion, detailed balance, collision invariants и optical power.
Температурные пределы внутри аналитических tests являются проверкой формул;
исследовательский пример использует 70 K.

Конфигурационные поля находятся в корневом mapping `physical_models`.
Варианты включаются по одному; прочие поля наследуют baseline:

| Вопрос | Поля |
|---|---|
| Screening | `screening: density_temperature`, `screening_temperature_K`, `screening_mass_ratio` |
| In-plane Kane | `dispersion: kane_inplane`, `nonparabolicity_per_eV` |
| Заданное N_LO | `lo_population: fixed_occupation`, `lo_fixed_occupation` |
| Rate-balance N_LO | `lo_population: rate_balance`, `lo_decay_ps`, `lo_mode_density_per_m3` |
| e–e SPPA | `electron_electron` с полями примера ниже |

Для `density_temperature` используется заданная ионизованная sheet density;
3D плотность равна ей, делённой на длину периода. Impurity получает 2D κ,
LO получает 3D κ. Это фиксированная термодинамическая оценка плотности из
постановки, а не локальная nonequilibrium polarizability.

Пример отдельного **исследовательского выбора параметров**, который не является
материальным fit или подтверждённым результатом QCL:

```yaml
physical_models:
  electron_electron:
    mode: sppa_single_q
    screening_dimension: 2
    transfer_wavenumber_per_nm: 0.1
    electron_temperature_K: 70
    effective_mass_ratio: 0.067
    carrier_density_per_m2: 4.5e14
    include_exchange: true
```

При `screening_dimension: 3` обязательно `carrier_density_per_m3` вместо
`carrier_density_per_m2`. Численные значения q, α, τ и mode density требуют
отдельного обоснования для конкретного исследования. Наличие исполняемого
SCBA пути и пройденных операторных tests не заменяет исследования сходимости
и сопоставления принятых J/distribution/gain состояний.
