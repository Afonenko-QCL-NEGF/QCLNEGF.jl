# [Физический и численный словарь](@id physics-glossary)

Словарь связывает названия с физическим содержанием; вывод формул расположен
в указанных главах. Английские сокращения сохранены только там, где они
встречаются в литературе или именах параметров.

| Термин | Определение и физический смысл | Глава |
|---|---|---|
| Базис | Набор функций для представления электронного состояния; усечение набора ограничивает доступное пространство состояний. | [Базис](@ref theory-basis) |
| Баланс частиц | Равенство суммарного притока и оттока электронов; внутреннее рассеяние перераспределяет, но не создаёт заряд. | [Наблюдаемые](@ref theory-observables) |
| Большая функция Грина ``G^>`` | Корреляционная функция, связанная с незанятой частью спектра; ``iG^>`` положительна полуопределённо. | [Функции Грина](@ref theory-greens) |
| Борновское приближение | Сохранение ведущего квадратичного по взаимодействию вклада рассеяния; самосогласованность использует в нём полные функции Грина. | [SCBA](@ref theory-scba) |
| Валидация | Проверка применимости модели через независимые физические данные. | [Проверки](@ref theory-validation) |
| Верификация | Проверка реализации уравнений и устойчивости численного результата при уточнении. | [Проверки](@ref theory-validation) |
| Вершинная поправка | Изменение взаимодействия и собственной энергии в ответ на внешнее возмущение; необходимо для полного согласованного оптического отклика. | [Оптика](@ref theory-optical-response) |
| Вложение | Замена исключённых внешних степеней свободы собственной энергией центральной области. | [Периодичность](@ref theory-periodicity) |
| Главное значение | Согласованный предел интеграла по обе стороны его сингулярной точки. | [Ядра](@ref theory-kernels) |
| Дисперсионный сдвиг | Вещественная часть собственной энергии, сдвигающая электронный резонанс. | [Ядра](@ref theory-kernels) |
| Запаздывающая функция Грина ``G^R`` | Амплитуда линейного отклика после приложения возмущения; определяет доступный спектр. | [Функции Грина](@ref theory-greens) |
| Инверсия населённостей | Превышение заполнения верхнего состояния над нижним в рассматриваемом оптическом переходе. | [Оптика](@ref theory-optical-response) |
| Когерентность | Фазовая корреляция амплитуд разных базисных состояний, представляемая внедиагональными элементами матрицы плотности. | [Наблюдаемые](@ref theory-observables) |
| Листовая плотность | Число частиц на площадь слоя после интегрирования объёмной плотности по ``z``. | [Масштабы](@ref theory-scaling) |
| Локализация | Выбор представления с пространственно сосредоточенными функциями; сама по себе не означает физического запирания электронов. | [Демонстрация](@ref localization-demonstration) |
| Меньшая функция Грина ``G^<`` | Корреляционная функция занятого электронного спектра; её интеграл даёт матрицу плотности. | [Функции Грина](@ref theory-greens) |
| Невязка | Норма нарушения уравнения текущим состоянием; должна иметь указанную нормировку и порог. | [Сходимость](@ref convergence-policy) |
| Неподвижная точка | Состояние, воспроизводимое нелинейным отображением самосогласованности. | [SCBA](@ref theory-scba) |
| Обусловленность | Чувствительность решения линейной задачи к малым изменениям входных данных. | [Масштабы](@ref theory-scaling) |
| Ортогонализация Лёвдина | Симметричное преобразование столбцов через обратный квадратный корень матрицы перекрытия. | [Базис](@ref theory-basis) |
| Положительная полуопределённость | Неотрицательность квадратичной формы матрицы для любого вектора, эквивалентная неотрицательности её собственных значений. | [Модель](@ref theory-model) |
| Причинность | Отсутствие отклика до возмущения; связывает дисперсию и уширение. | [Ядра](@ref theory-kernels) |
| Самосогласование | Совместное решение взаимозависимых спектра, заполнения, рассеяния и поля. | [Пуассон](@ref theory-outer-loop) |
| Собственная энергия ``Σ`` | Эффективный оператор влияния рассеяния или исключённых степеней свободы на электронное состояние. | [Ядра](@ref theory-kernels) |
| Спектральная функция ``A`` | Матрица распределения доступного электронного веса по энергии. | [Функции Грина](@ref theory-greens) |
| Уширение ``Γ`` | Антиэрмитова часть собственной энергии, связанная с конечным временем жизни и рассеянием. | [Ядра](@ref theory-kernels) |
| Хартри, поле | Средний электростатический потенциал распределённого электронного и донорного заряда. | [Пуассон](@ref theory-outer-loop) |
| Экранирование | Ослабление кулоновского поля за счёт отклика среды; статическая модель задаётся отдельными параметрами. | [Ядра](@ref theory-kernels) |
| LO | Продольные оптические фононы: полярные колебания, переносящие конечную энергию между электронами и решёткой. | [Ядра](@ref theory-kernels) |
| IFR | Шероховатость интерфейсов, создающая случайный потенциал из смещения границ материалов. | [Ядра](@ref theory-kernels) |
| NEGF | Метод неравновесных функций Грина, совместно описывающий спектр и заполнение открытой квантовой системы. | [Модель](@ref theory-model) |
| PzP | Проекция координатного оператора в выбранное подпространство для построения локализованных комбинаций. | [Базис](@ref theory-basis) |
| SCBA | Самосогласованное борновское приближение для собственных энергий рассеяния. | [SCBA](@ref theory-scba) |

Контрольная точка (checkpoint) означает полное сохранённое численное
состояние, достаточное для согласованного продолжения при совместимом
контракте. Серия по параметру (sweep) означает набор независимых или
последовательно связанных рабочих точек. Учебный малый эталон (oracle)
проверяет формулу, а не экспериментальную точность. Расчёт с предупреждением
о приближённом качестве (approximate) должен сохранять эту характеристику
при построении сводных таблиц и сравнении методов.
