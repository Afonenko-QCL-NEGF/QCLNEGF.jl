# [16. Полный контракт входов](@id full-input-contract)

Эта глава сопоставляет типизированные определения домена, базовые профили и
размерности и формы результата. Формулы и числа изменяются одним
проверяемым набором правок, который синхронизирует реализацию, параметры, тесты
и эту таблицу; машинно-проверяемые связи перечислены в
[карте исходников](@ref developer-source-map).

## Фундаментальные константы

Фундаментальные константы находятся в [`CODATA`](@ref) как
`Unitful.Quantity`; единицы отбрасываются только после явного `uconvert`.

| Поле | Значение | Физическая размерность |
|---|---:|---|
| ``e`` | ``1.602176634\times10^{-19}`` | C |
| ``\hbar`` | ``1.054571817\times10^{-34}`` | J s |
| ``\hbar_{eV}`` | ``6.582119565476075\times10^{-16}`` | eV s, вычислено из сохранённого значения СИ и точного ``e`` |
| ``k_B`` | ``1.380649\times10^{-23}`` | J K``^{-1}`` |
| ``k_{B,eV}`` | ``8.617333262145179\times10^{-5}`` | eV K``^{-1}``, вычислено из сохранённого значения СИ и точного ``e`` |
| ``m_0`` | ``9.1093837139\times10^{-31}`` | kg |
| ``\epsilon_0`` | ``8.8541878128\times10^{-12}`` | F m``^{-1}`` |

Кинетический множитель не является ещё одним входом: `C₀` вычисляется как
`uconvert(u"eV*nm^2", CODATA.ħ^2 / (2CODATA.m₀))` и для этой таблицы равен
примерно ``0.03809982106299685\;\mathrm{eV\,nm^2}``. Поэтому в исполняемом
коде нет независимо округлённой копии этой величины.

## Численный паспорт `NumericalParameters`

| Поле | Базовый набор | Размерность | Дискретный смысл |
|---|---:|---|---|
| `N_z` | 198 | 1 | равномерная сетка ``z`` с узлами в центрах ячеек |
| `N_b` | 5 | 1 | локальные состояния ячейки |
| `P_basis` | 3 | 1 | окно из ``2P+1=7`` периодов |
| `E_min,E_max,N_E` | -0.15, 0.45, 2401 | eV, eV, 1 | равномерная формула трапеций |
| `M_E` | 56 | meV | граница доверенного окна преобразования Гильберта |
| `k_max,N_k` | 0.60, 61 | nm``^{-1}``, 1 | радиальные кольцевые ячейки |
| `N_φ` | 64 | 1 | периодическое угловое среднее |
| `qz_max,N_qz` | 10, 401 | nm``^{-1}``, 1 | симметричная формула трапеций |
| `η_seed` | 0.5 | meV | только начальное приближение; рабочее значение равно нулю |

`M_E` обязан удовлетворять
``M_E\ge\max(E_p,\hbar\omega_{LO})``. `ModelGrids.trusted_energy` —
`BitVector` длины ``N_E`` для узлов
``E_{min}+M_E\le E_e\le E_{max}-M_E``.

## Опции и критерии

[`ScatteringOptions`](@ref) включает `LO`, `acoustic`, `impurity`, `IFR`,
`alloy`. [`SolverOptions`](@ref) содержит общие коэффициенты смешивания,
защитные ограничения, [`SolverTolerances`](@ref) и явно заданные доли хвостовых
окон валидации по энергии и ``k``. Строгие значения по умолчанию:

```math
r_D<10^{-11},\quad r_A<10^{-9},\quad
r_K,r_\Sigma,r_\lambda<10^{-8},
```

```math
r_P<10^{-11},\quad r_U,r_n<10^{-7},\quad
r_{neutral},|\zeta|<10^{-10},\quad r_J<10^{-6},
```

```math
r_{C,s}<10^{-8},\quad r_{power}<10^{-4},\quad
r_{PSD},r_{caus}<10^{-10},\quad r_{sum}<10^{-3}.
```

Относительные изменения тока и населённостей меньше ``10^{-4}``; занятые доли
краёв меньше ``10^{-6}``. Поточечные мнимые следы и обратный порядок
суммирования проверяются отдельно. Любые `NaN`/`Inf` означают отказ.

## Формы и единицы результата

| Поле | Размер | Тип | Масштаб | Вывод |
|---|---:|---|---|---|
| `Uᴴ` | ``(N_z)`` | F64 | ``U_H/E_0`` | eV |
| `n` | ``(N_z)`` | F64 | ``L_0^3n`` | m``^{-3}`` |
| `Gᴿ,Gˡ,Gᵍ,A` | ``(N_E,N_k,N_b^{\times2})`` | C64 | ``E_0G`` | eV``^{-1}`` |
| `Σᴿ,Σˡ,Σᵍ` | та же | C64 | ``\Sigma/E_0`` | eV |
| `Khat_s` | ``(N_k^{\times2},N_b^{\times4})`` | C64 | нормировано | `qᴷ` восстанавливает ``\bar K`` |
| `h` | ``(N_k,N_b^{\times2})`` | C64 | ``H/E_0`` | eV |
| `condition_number` | ``(N_E,N_k)`` | F64 | 1 | число потерянных цифр оценивается по ``\log_{10}\kappa`` |

Здесь ``N_b^{\times p}`` означает ровно ``p`` последовательных осей длины
``N_b`` (не степень длины оси); аналогично для ``N_k^{\times p}``. Полные
порядки осей: ``G^{R,<,>,A}_{e m a b}`` — ``(E,k,a,b)``, а
``\widehat K_{m m' a c d b}`` — ``(k,k',a,c,d,b)``. Сокращения типов
``F64`` и ``C64`` означают соответственно `Float64` и `ComplexF64`.

Преобразования выполняют [`scaled_value`](@ref) и [`physical_value`](@ref).
Контрольная точка [фиксирует оси и единицы явно](https://github.com/AfonenkoA/QCLNEGFRunner.jl/blob/main/docs/src/user/results.md).

Приближённая полоса качества включается явно через численные опции.
Она не изменяет строгие критерии и требует отдельного статуса результата.
[Политика сходимости](@ref convergence-policy) описывает интерпретацию этих состояний.
