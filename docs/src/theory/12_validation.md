# [12. Верификация](@id theory-validation)

Верификация отвечает на вопрос, решены ли записанные уравнения правильно.
Физическая валидация отвечает на другой вопрос: достаточно ли этих уравнений
для описания выбранного эксперимента. Тест скалярного лоренциана проверяет
знак и нормировку функции Грина; он не доказывает правильности всех
механизмов рассеяния лазера.

## [Машиночитаемый паспорт критериев](@id acceptance-metadata-registry)

`solution_scientific_assessment` публикует версионированный паспорт
`qcl-negf-acceptance-metadata-v1`. Для каждого применяемого финального критерия
он содержит формулу, ссылку на единственную вычисляющую её функцию, единицы,
область применимости, квадратурные веса, нормировку и точный защитный floor
знаменателя. Численные веса энергии, радиального импульса и координаты
передаются один раз на весь паспорт вместе с масштабами `E0`, `L0`, `lambda_P`
и размером базиса. Формулы из паспорта не вычисляются повторно в API или UI.

Программный реестр находится в `src/numerics/reference/acceptance_metadata.jl`.
Его полнота проверяется против всех ключей `_solution_validation_limits`,
включая критерии каждого канала рассеяния и дополнительные e–e/hot-LO критерии.
Неизвестный новый критерий требует явного дополнения реестра. В частности,
паспорт различает floor `max(norm,eps(Float64))` у product integration и
`norm+1e-14` у direct/FFT: одинаковое назначение диагностики не означает
одинаковую формулу нормировки.

| Статус метрики | Значение |
|---|---|
| `pass` / `fail` | Есть конечное измерение применимого критерия; оно сопоставлено с заданным порогом. |
| `not_measured` | Нет измерения, необходимой истории либо фактической независимой проверки преобразования. |
| `not_applicable` | Критерий относится к явно выключенному механизму или отсутствующему оператору; сохраняется основание. |
| `error` | Применимое измерение неконечно или вычисление не имеет корректного результата. |

Нулевое значение старого численного поля не превращает отключённую проверку
в пройденную: например, при отсутствии внутреннего рассеяния диагностика
края `Gamma_sc` неприменима, а при отключённом повторном преобразовании
Гильберта ошибка roundoff не измерена. Исходное численное поле при наличии
сохраняется отдельно как `recorded_value`.

Порог отмечается как параметр проектной политики `SolverTolerances`, а не
универсальная константа NEGF из статьи. Сам порог не является оценкой ошибки.
Паспорт указывает класс ошибки и требуемое независимое свидетельство;
неполученная оценка границы ошибки остаётся `not_measured`. Для PSD отдельно
описан применённый allowance `64*Nb*eps(Float64)*max(block_norm,1)`; он учитывает
объявленный масштаб ошибок построения/диагонализации и не заменяет сеточную
проверку. Аналогично, изменение порядка суммирования измеряет чувствительность
к арифметике, но не является строгой границей ошибки наблюдаемой.

Финальный evaluator отклоняет `value > threshold`, то есть принимает равенство.
Подтверждающие последовательности inner/outer iterations используют строгое
`value < threshold`. Паспорт явно различает эти два сравнения. Наличие
принятого стационарного кандидата фиксируется отдельно от научной приёмки:
до независимых сравнений дискретизации одиночная точка не получает
`scientific_accepted=true`.

Для невязки линейного уравнения удобно отношение нормы остатка к нормам
слагаемых. Для закона сохранения сравниваются независимо вычисленные
потоки. Для сеточной ошибки нужна последовательность решений на нескольких
сетках. Смешение этих величин в единый «процент точности» лишает оценку
физического смысла.

## [EQ-VALIDATE-001 — полный критерий приёмки](@id eq-validation-residuals)

[`validate_problem`](@ref) до SCBA проверяет:

- сумму по слоям и донорам и все формы массивов;
- ``\Phi^\dagger\Phi=I`` и обусловленность ``S^{cell}``;
- ``T_-=T_+^\dagger`` и эрмитовость каждого ``H(k)``;
- отсутствие циклического энергетического замыкания для обоих направлений
  сдвига полем и энергией продольного оптического фонона; проверка учитывает
  [узловую либо конечно-объёмную дискретизацию](@ref eq-energy-shift);
- неотрицательность коэффициентов переноса, правильные суммы строк и,
  для переноса средних по ячейкам, взвешенную сопряжённость направлений;
- составную эрмитовость и положительную полуопределённость каждого ядра;
- `r_eigen`, проверку переноса центрального периода, точную нормировку ядра и
  непустое доверенное окно преобразования Гильберта.

[`validate_solution`](@ref) после внешнего цикла проверяет:

```math
A\succeq0,\quad-iG^<\succeq0,\quad iG^>\succeq0,
\quad \operatorname{Im}_H\Sigma^R\preceq0,
```

```math
\sum_e\frac{w_e^{(E)}}{2\pi}A(E_e,k_m)\simeq I,
```

баланс частиц каждого механизма, два необработанных тока через границы,
энергетический баланс и нейтральность. Ни один нарушенный инвариант не
исправляется симметризацией или отсечением.

Отдельно, чтобы ошибки не сокращались между каналами, тождества и причинность
проверяются для ``\Sigma_{sc}``, ``\Sigma_{emb}`` и их суммы. Мнимые части
следов тока и столкновений проверяются поточечно для каждого ``(E_e,k_m)``.
Крайние доли энергетических узлов и узлов ``k``, заданные
`solver.validation_windows.energy_tail_fraction` и
`momentum_tail_fraction` (в базовом профиле 5% и 10%), дают `r_tail`; нормы на
границе ``\Gamma_{sc}`` и ``\operatorname{Tr}A`` дают `r_edge`. Итоговая пара
``(u_H,n)`` проходит повторное окаймлённое решение уравнения Пуассона.

Пример последовательностей уточнения, которые следует адаптировать к
ширине реальных спектральных особенностей:

```math
k_{max}=0.45,0.60,0.75\;\mathrm{nm^{-1}},\quad
\Delta E=0.50,0.25,0.125\;\mathrm{meV},
```

```math
N_b=5,6,7,\qquad N_p^{basis}=5,7,9.
```

Регрессионная сверка Julia–Wolfram сравнивает каждый элемент
``H,T,K,\Sigma,G,n,U_H``.

## [Спектральное правило суммы и разрешение по энергии](@id validation-spectral-sum)

Спектральная матрица распределяет вес состояний по энергии. В ортонормированном
базисе интеграл по всей энергетической оси восстанавливает единичную матрицу:
каждому базисному состоянию соответствует единичный полный спектральный вес.
Это условие связано с нормировкой функции Грина и отличается от выполнения
уравнения Дайсона в отдельных узлах, рассмотренного в
[главе о функциях Грина](@ref theory-greens).

На конечной сетке проверяется матрица

```math
M(k_m)=\sum_e\frac{w_e^{(E)}}{2\pi}A(E_e,k_m),\qquad
r_{sum}=\max_m\frac{\|M(k_m)-I\|_F}{\sqrt{N_b}}.
```

Здесь ``\|\cdot\|_F`` — квадратный корень суммы квадратов модулей всех
элементов. Поэтому ``r_{sum}`` измеряет отклонение всей матрицы, включая
межуровневые элементы; оно не равно доле недостающих частиц или относительной
ошибке тока. След ``\operatorname{Tr}M`` должен стремиться к ``N_b``, но один
только правильный след не гарантирует правильности матрицы.

Реальный диагностический пример даёт структура reference design из профиля
`studies/pilot_reference` при 200 K и 56 mV на период. На сетке из 121 узла
между −0.12 и 0.40 eV шаг составляет приблизительно 4.333 meV. Прямой и
оптимизированный алгоритмы завершили внутреннюю итерацию и 15 шагов Пуассона,
а рассчитанные токи совпали с относительным отклонением около
``7.6\times10^{-16}``. Однако независимая конечная проверка дала
``r_{sum}=0.4328281769`` при объявленном пределе 0.05. При ``k=0`` след
интеграла составил приблизительно 2.00058 вместо 3. Совпадение реализаций
в данном случае подтверждает вычисление одного дискретного приближения;
приёмку физических результатов оно не обеспечивает.

Проверка положительности в этом состоянии дала нулевой дефект, невязка
тока через границы — ``5.9623\times10^{-4}`` при пределе ``10^{-3}``, а
невязка баланса мощности — ``2.2760\times10^{-5}`` при пределе 0.05.
Следовательно, отказ обусловлен спектральным правилом суммы. Увеличение
числа разрешённых итераций само по себе не уточняет энергетическую
квадратуру. Особенно опасны узкие пики между соседними узлами: нелинейное
уравнение на имеющейся сетке может быть решено, а площадь пика — существенно
недооценена.

Для локализации причины сохраняют конечный потенциал Хартри и независимо
сравнивают две последовательности внутренних решений: сгущение узлов при
неизменных границах и расширение окна при неизменном шаге. Первая проверяет
разрешение резонансов, вторая — потерю спектральных хвостов. Это диагностический
эксперимент с фиксированным полем, а не новый самосогласованный результат.
В этом примере удвоение числа интервалов при сохранении окна снизило
``r_{sum}`` до 0.185792 (241 узел, шаг 2.167 meV; внутреннее состояние
принято только в приближённой полосе). Расширение окна до [−0.25, 0.79] eV
при прежнем шаге 4.333 meV оставило невязку около 0.432707; эта проба
остановилась на проверке физического качества внутреннего состояния и
служит только диагностикой. Такое сравнение указывает прежде всего на
недостаточное разрешение по энергии; ни одна из этих двух проб не прошла
правило суммы с пределом 0.05. Дальнейшее сгущение до 521 узла (шаг 1 meV)
снизило невязку до 0.071203; после 983 внутренних итераций состояние принято
в приближённой полосе SCBA, но спектральный критерий всё ещё не выполнен.
Эти данные не позволяют объявить ни одну исследованную сетку эталонной или
заменить проверку увеличением допуска.

После выбора сетки необходимо повторить полный
[цикл Пуассон–SCBA](@ref theory-outer-loop) и проверить наблюдаемые на следующей
сетке. Диапазон разрешённой приближённой сходимости не отменяет правило суммы.

Полный набор конечных невязок, строгих и объявленных приближённых порогов,
а также причины отклонения сохраняются в `validation.yaml` и `validation.csv`
рядом с каждым лёгким снимком. Флаг `evaluated: false` означает, что снимок
промежуточный и конечная проверка ещё не выполнена. Обычная таблица sweep
включает `spectral_sum`; предупреждение `FINAL_VALIDATION_FAILED` переносит
причину в сводку сравнения и состояние задания. HDF5 для этого разбора не нужен.

## Локализация нарушения положительности

Положительная полуопределённость спектральной матрицы выражает
неотрицательность спектральной плотности для любого нормированного
состояния. Для заполненной и незаполненной частей это же условие
применяется к ``-iG^<`` и ``iG^>`` соответственно. Поэтому проверка одного
следа матрицы недостаточна: положительный след может скрывать отрицательное
собственное значение, компенсированное другими состояниями.

Для каждой матрицы ``X`` в точке ``(E_e,k_m)`` вычисляются эрмитова часть
``H_X=(X+X^\dagger)/2``, наименьшее собственное значение и спектральная
норма. Локальный нормированный дефект имеет вид

```math
r_{PSD}(E_e,k_m;X)=
\frac{\max(0,-\lambda_{\min}(H_X))}
     {\|H_X\|_2+\varepsilon_{floor}}.
```

Положительная добавка ``\varepsilon_{floor}`` ограничивает влияние деления
на практически нулевую норму. Она входит только в определение диагностики
и не изменяет матрицу. Все величины в этой формуле вычисляются в
[масштабированных единицах](@ref theory-scaling).

Максимум по сетке может находиться в слабом спектральном хвосте. Если
отрицательное собственное значение сравнимо с нормой именно этого блока,
отношение близко к единице даже при небольшой абсолютной величине блока.
Обратное также возможно: такой же максимум возникает в существенной части
спектра. Различить эти ситуации по единственному числу ``r_{PSD}`` нельзя.
Поэтому лёгкие результаты сохраняют для каждой из четырёх проверяемых
матриц — ``A``, ``-iG^<``, ``iG^>`` и ``i(\Sigma^>-\Sigma^<)`` — координаты
худшего блока, его минимальное собственное значение, норму и значение
допуска. Отдельные файлы `positivity_diagnostics.yaml` и
`positivity_diagnostics.csv` формируются по всей сетке независимо от
прореживания графиков; наличие HDF5 для этого не требуется.

Диагноз затем сопоставляют с картами спектральной плотности, заполнения
и границами окна. Для исследования распределённой ошибки полезно также
интегрировать отрицательную часть спектра собственных значений с теми же
энергетическими и импульсными весами, которые входят в наблюдаемые.
Такая интегральная оценка дополняет поточечный критерий, но не заменяет
его и не является разрешением отсечь отрицательные значения.

Постоянство максимального физического дефекта само по себе не доказывает
остановку нелинейной итерации. Невязки уравнения Келдыша, собственной
энергии и наблюдаемых могут продолжать уменьшаться при насыщенном
нормированном дефекте положительности. Прогресс неподвижной точки и
физическая допустимость поэтому проверяются отдельно; порядок остановки
и допустимого приближённого завершения определён в
[политике сходимости](@ref convergence-policy).

## Приёмка приближённого состояния

Объявленная полоса приближённой сходимости может ослаблять отдельные
невязки неподвижной точки и физического качества. Это не означает
отключения всей функции проверки. Итоговый отчёт сохраняет строгий и,
если разрешён, приближённый результат проверки и причины различия.
Описание конкретных допусков и их распространения дано в
[главе о качестве](@ref convergence-policy).

## План уточнения

Сначала увеличивают границы энергии и импульса при неизменных шагах,
чтобы оценить отброшенные хвосты. Затем сгущают сетки при фиксированных
достаточных границах. Базис уточняют независимо по числу состояний и длине
окна. Для `finite_chain` отдельно увеличивают число соседних периодов,
для примесной квадратуры — точность интегрирования по углу.

Для каждого шага сохраняют ток, плотность, положения и ширины пиков,
оптическое качество, если отклик рассчитан, и все балансы. Изменение
одного наблюдаемого может быть малым вследствие компенсации нескольких
ошибок. Прямой и обратный проход по напряжению вместе с независимым
начальным приближением помогает отделить численную зависимость от
возможной множественности стационарных ветвей.

Практическая связь тестов и формул описана в
[проверках физических свойств](@ref theory-validation), а примеры
визуального контроля — в [атласе](@ref physical-atlas).

Вывод описанных диагностик в файлы и графики предоставляет
[QCLNEGFRunner.jl](https://github.com/Afonenko-QCL-NEGF/QCLNEGFRunner.jl);
ядро возвращает состояния и метрики в памяти.
