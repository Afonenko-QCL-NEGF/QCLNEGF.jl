# [14. Численные масштабы и стоимость](@id theory-cost)

Стоимость определяется числом одновременно сохраняемых степеней свободы
и структурой операций. Удвоение числа состояний существенно дороже
удвоения числа энергетических узлов: четыре базисные оси ядра дают
четвёртую степень, а матричное решение Дайсона — третью. Поэтому
уменьшать базис ради памяти допустимо только вместе с
[исследованием его погрешности](@ref theory-basis).

## Размер основных массивов

Для базовой сетки ``(N_E,N_k,N_b)=(2401,61,5)`` один полный
`Array{ComplexF64,4}` формы ``(N_E,N_k,N_b,N_b)`` содержит
``3\,661\,525`` элементов и занимает 55,87 МиБ. Семейство запаздывающей,
меньшей и большей компонент занимает 167,6 МиБ. Несколько механизмов
рассеяния, кандидаты итераций и служебные поля требуют одновременного хранения
нескольких таких массивов.

Полное ядро, зависящее от поперечного импульса, имеет форму
``(N_k,N_k,N_b,N_b,N_b,N_b)`` и содержит ``(N_kN_b^2)^2`` комплексных
значений. Для базовой сетки это 35,49 МиБ на механизм. Плоское представление
в [`production_static_contraction`](@ref) хранит то же число коэффициентов:
оно меняет порядок данных, но не является низкоранговым приближением.

## Работа учебной реализации E0

Для одной полной карты статической собственной энергии и прямой суммы
Гильберта:

```math
C_{\mathrm{Dyson}}=O(N_EN_kN_b^3),
```

```math
C_{\mathrm{static}}=O(N_EN_k^2N_b^4),
\qquad
C_{\mathrm{Hilbert,direct}}=O(N_E^2N_kN_b^2).
```

Для базовой сетки соответствующие размерные множители равны примерно
``1.83\times10^7``, ``5.58\times10^9`` и ``8.79\times10^9``. Учебные
[`solve`](@ref) и [`solve_scba`](@ref) намеренно используют плотные
матрицы энергетического сдвига, буквальные шестимерные суммы и прямую
``O(N_E^2)`` сумму главного значения. Эта ветвь остаётся формульным эталоном
для малых сеток и не получает автоматических оптимизаций исполнения.

## Работа точной реализации E1

Рабочая реализация меняет организацию той же дискретной карты:

- разреженный энергетический сдвиг имеет стоимость ``O(N_E)`` вместо
  умножения на плотную матрицу ``N_E\times N_E``;
- полная карта ядра сохраняет ``O(N_EN_k^2N_b^4)``, но вычисляется блочными
  матричными произведениями BLAS;
- независимые от импульса акустическое и сплавное рассеяния используют точную
  факторизацию;
- линейное FFT с нулевым дополнением имеет стоимость
  ``O(N_EN_kN_b^2\log N_E)`` вместо прямой суммы
  ``O(N_E^2N_kN_b^2)``;
- набор невязок вычисляется одним блочным проходом с повторным использованием
  памяти;
- начальное значение химического потенциала повторно использует заранее
  вычисленные квадратурные веса.

Число карт свёртки входит в оценку явно. Упругий механизм имеет по карте для
``<`` и ``>``, а LO-рассеяние — карты испускания и поглощения для обеих
компонент. Поэтому задача может оставаться вычислительно тяжёлой даже при
умеренном объёме явных массивов.

## Параллельные рабочие области

При `parallel_backend=:threads` каждый из ``P_c`` исполнителей свёртки
хранит две комплексные матрицы

```math
X_p,Y_p\in\mathbb C^{(N_kN_b^2)\times C_E},
```

где ``C_E=\min(\texttt{energy\_chunk},N_E)``. Их явный объём равен

```math
W_{\mathrm{GEMM}}=
2P_cN_kN_b^2C_E\,\operatorname{sizeof}(\mathrm{ComplexF64}).
```

В режиме `:blas` внешняя свёртка использует одного исполнителя, а
многопоточность обеспечивает BLAS.

План [`ProductionFFTHilbertPlan`](@ref) хранит для каждого исполнителя
комплексный буфер ``L_{FFT}\times C_H``, где
``L_{FFT}=2^{\lceil\log_2(2N_E-1)\rceil}`` и
``C_H\le\texttt{hilbert\_columns}``, а также образ ядра в частотной области.
При `verify_fft_roundoff=true` добавляется независимая рабочая область с
удвоенной длиной:

```math
W_{\mathrm{FFT}}=
\operatorname{sizeof}(\mathrm{ComplexF64})
\left[L_{FFT}(1+P_HC_H)+2L_{FFT}(1+P_HC_H)\right].
```

Точное значение явных буферов готового плана возвращает
[`production_fft_workspace_bytes`](@ref). Метаданные FFTW и выходной массив
в эту величину не входят.

Память [`ProductionResidualWorkspace`](@ref) масштабируется как
``O(N_EN_k)`` вещественных значений плюс ``O(P_rN_b^2)`` малых матриц. Она
устраняет повторные выделения и сохраняет воспроизводимый порядок редукций.

## Явный бюджет вычисления

Полезный параллелизм ограничен числом энергетических блоков и независимых
матричных задач. `ProductionOptions` задаёт расписание; выбор процессоров и
проверка cgroup относятся к
[QCLNEGFRunner.jl](https://github.com/Afonenko-QCL-NEGF/QCLNEGFRunner.jl/blob/main/docs/src/user/resources.md).

`estimate_production_memory` оценивает одновременно живущие научные массивы и
рабочие области. Это не гарантия RSS: распределитель памяти, сборщик мусора,
BLAS и FFTW могут удерживать дополнительные страницы. Сравнивайте оценку с
измеренным пиковым потреблением и фактическим ограничением процесса.

## Масштабирование Float64

Характерные безразмерные величины:
``E_p/E_0=0.56``, ``\hbar\omega_{LO}/E_0=0.367`` и
``N_D^{2D}L_0^2=0.045``. Спектральный пик ``E_0A`` может лежать в диапазоне
40–400; это физический динамический диапазон, а не признак неверного
масштабирования.

В численном состоянии используются три локальных масштаба:
``E_{grid,0}\simeq50.85`` эВ,
``s_{em}=\max_a\sum_b|D^R_{em,ab}|`` и
``q_s^K=\max|\bar K_s|``. Они масштабируют соответственно задачу на
собственные значения, блок Дайсона и полную свёртку ядра, не меняя физическую
единицу результата.

В `real_space` число состояний равно числу координатных узлов. Плотные
шестиосевые ядра поэтому ограничивают размер такого эталона гораздо
раньше, чем один координатный гамильтониан. Конечное цепочечное вложение
добавляет работу исключения по числу соседей, а адаптивная угловая
квадратура имеет зависящее от параметров число обращений к ядру.
Приведённые оценки полных операторов нельзя выдавать за измерение времени
этих режимов. Для сравнения необходимо сохранять выбранный алгоритм и
[распределения длительностей](@ref theory-visualization).
