# [3. Индексы, сетки и формы массивов](@id array-contracts)

Дискретизация заменяет непрерывные интегралы конечными взвешенными суммами.
Поэтому смысл индекса и его веса является частью физической формулы.
Ниже диапазоны указаны в индексации Julia от единицы; в экспортируемом
формате начало отсчёта должно быть записано явно. Математический индекс
можно перенумеровать без изменения формулы, но нельзя переставить оси
тензора без одновременного изменения свёртки.

| Индекс | Диапазон Julia | смысл |
|---|---|---|
| ``g`` | `1:N_z` | координатная ячейка |
| ``a,b,c,d`` | `1:N_b` | локальные состояния ячейки |
| ``e`` | `1:N_E` | энергетический узел |
| ``m,m^{\prime}`` | `1:N_k` | радиальные узлы импульса |
| ``r`` | `1:N_φ` | угловой узел |
| ``h`` | `1:N_qz` | продольный импульс фонона |
| ``\nu,\mu`` | положительные целые числа | итерации SCBA/Пуассона |

Базовый набор [`baseline_numerics`](@ref):

```math
N_z=198,\;N_b=5,\;N_E=2401,\;N_k=61,\;N_\varphi=64,
\;N_{q_z}=401.
```

Для функции, не зависящей от направления поперечного импульса,
``\int d^2k/(2\pi)^2=\int_0^\infty k\,dk/(2\pi)``. Следовательно,
равномерная сумма по ``k`` без множителя ``k`` не является двумерным
интегралом. Радиальный вес уже содержит меру ``d^2k/(2\pi)^2``:

```math
w_m^{(k)}=\frac{b_{m+1/2}^2-b_{m-1/2}^2}{4\pi}.
```

Энергетические веса аппроксимируют только ``\int dE``; множитель
``1/(2\pi)`` всегда остаётся в формулах.

| Объект | Форма массива Julia | внутренний тип | структура |
|---|---:|---|---|
| ``H^{grid}`` | `(N_z,N_z)` | `Float64` | полная запись логически трёхдиагональной матрицы |
| ``\Phi,\chi`` | `(N_z,N_b)` | `ComplexF64` | ортонормированные столбцы |
| ``H(k)`` | `(N_k,N_b,N_b)` | `ComplexF64` | полные эрмитовы блоки |
| ``T_\pm`` | `(N_b,N_b)` | `ComplexF64` | полные блоки, ``T_-=T_+^\dagger`` |
| ``G^{R,<,>},\Sigma^{R,<,>}`` | `(N_E,N_k,N_b,N_b)` | `ComplexF64` | полные блоки |
| ``K^s`` | `(N_k,N_k,N_b,N_b,N_b,N_b)` | `ComplexF64` | порядок ``m,m',a,c,d,b`` |
| ``F^{LO}`` | `(N_qz,N_b,N_b)` | `ComplexF64` | порядок ``h,a,c`` |
| ``W^{(\delta)}`` | `(N_E,N_E)` | `Float64` | плотный нециклический сдвиг |
| маска доверенной области преобразования Гильберта | `(N_E)` | `BitVector` | отступ ``M_E=56`` meV от обоих краёв |
| ``L_P`` | `(N_z,N_z)` | `Float64` | циклическая трёхдиагональная матрица ранга ``N_z-1`` |
| ``q_s^K`` | по одному на механизм | `Dict{Symbol,Float64}` | точный масштаб ядра |

`KernelSet.K[s]` хранит нормированное ``\widehat K_s``; умножение на
`KernelSet.qᴷ[s]` внутри каждой свёртки точно восстанавливает ``\bar K_s``.

Проверяемые конструкторы: [`build_grids`](@ref), [`build_profiles`](@ref),
[`build_shift_matrix`](@ref).

## Разрешение и область определения

Шаг энергии определяет, различаются ли соседние спектральные пики и
уширения, тогда как границы энергии определяют, не отброшена ли существенная
часть спектрального веса. Эти проверки независимы. Аналогично увеличение
``N_k`` уточняет интеграл в заданном круге, а увеличение ``k_max``
расширяет саму физически учитываемую область импульсов.

Угловая квадратура нужна для микроскопической передачи импульса
``q=\sqrt{k^2+k'^2-2kk'\cos\varphi}``. Вблизи прямого рассеяния малые
углы особенно существенны для кулоновского ядра; одинаковое число углов
не означает одинаковую погрешность разных механизмов. См.
[квадратуры ядер](@ref theory-kernels).

Размеры в таблице описывают полное представление. Оптимизированная
реализация может хранить энергетический сдвиг разреженным планом,
консервативной парой матриц или факторизованный оператор рассеяния.
Физические оси и веса от этого не меняются. Связь памяти и размеров
выведена в [главе о стоимости](@ref theory-cost).
