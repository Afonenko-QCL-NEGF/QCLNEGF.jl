# [6. Связь периодов и энергетическое окно](@id theory-periodicity)

Повторение слоёв в постоянном поле не означает повторение спектра при той
же абсолютной энергии. В следующем периоде электронная потенциальная
энергия ниже на ``E_p``. Поэтому перенос обоих пространственных индексов
на ``s`` периодов сопровождается энергетическим сдвигом:

```math
X_{p+s,a;q+s,b}(E,k)=X_{pa;qb}(E-s\Delta_E,k),\qquad \Delta_E=-E_p.
```

Это позволяет описывать центральную ячейку, сохраняя информацию о соседях.
Знаки следуют из [соглашения о поле](@ref theory-model), а не выбираются по
тому, какой знак тока кажется привычным.

## [Нециклический энергетический сдвиг](@id eq-energy-shift)

Для сдвига ``\delta`` требуется значение функции между узлами сетки:

```math
[\mathcal S_\delta X]_e=\sum_{e'}W^{(\delta)}_{ee'}X_{e'}
\simeq X(E_e+\delta).
```

`dense` и `sparse_plan` вычисляют одну кусочно-линейную интерполяцию,
различаясь хранением. За пределами энергетического окна значение нулевое;
перенос с верхнего края на нижний создавал бы искусственное заполнение
состояний. Нулевое продолжение тоже является численным граничным условием,
поэтому край окна должен лежать вне существенно занятой области.

### Узловые значения и средние по энергетической ячейке

При линейной интерполяции неизвестные представляют значения функции
в узлах ``E_e``. Если ``E_e+\delta`` лежит между двумя соседними узлами,
соответствующая строка оператора имеет два неотрицательных коэффициента,
сумма которых равна единице. Если сдвинутый узел находится вне окна,
вся строка равна нулю. Это именно условие на **узловое значение**.

`conservative_pair` использует другую дискретизацию. Вокруг каждого узла
задаётся энергетическая ячейка ``C_e=[b_e,b_{e+1}]``; внутренние границы
проходят через середины промежутков между узлами, а внешние совпадают
с границами окна. Величина ``X_e`` интерпретируется как среднее по ячейке,
внутри которой функция аппроксимируется постоянной. Обозначим ширину
ячейки через ``w_e=b_{e+1}-b_e``. Тогда сдвиг равен среднему перенесённой
функции и выражается через длины пересечений:

```math
[S_\delta]_{ee'}=
\frac{|(C_e+\delta)\cap C_{e'}|}{w_e}.
```

Пересечение понимается в исходном конечном энергетическом окне. Поэтому
коэффициенты неотрицательны, а сумма строки равна доле сдвинутой ячейки,
которая остаётся внутри окна:

```math
\sum_{e'}[S_\delta]_{ee'}=
\frac{|(C_e+\delta)\cap[E_{\min},E_{\max}]|}{w_e}\leq1.
```

Вблизи границы центр ячейки может уже выйти из окна, хотя часть ячейки
ещё пересекает его. В таком случае ненулевая строка необходима для
правильного переноса интеграла; применять к ней правило обнуления
сдвинутого **узла** нельзя. Например, для сетки от ``-1`` до ``8`` эВ
из ``1025`` узлов шаг равен ``8.7890625`` мэВ. При сдвиге на ``-56`` мэВ
центр седьмой ячейки оказывается ниже нижней границы, но её пересечение
с первой ячейкой имеет ширину ``1.12890625`` мэВ. Коэффициент переноса
равен ``1.12890625/8.7890625\simeq0.128444``. Такой вклад не означает
циклического перехода между противоположными краями окна.

### Взвешенная сопряжённость двух направлений

Геометрическая симметрия пересечений даёт
``|(C_e+\delta)\cap C_{e'}|=|C_e\cap(C_{e'}-\delta)|``.
Если ``W_E=\operatorname{diag}(w_e)``, отсюда следует

```math
W_E S_+=S_-^\dagger W_E,\qquad S_\pm=S_{\pm\delta}.
```

В скалярном произведении с энергетическими весами это означает
``\langle x,S_+y\rangle_{W_E}=\langle S_-x,y\rangle_{W_E}``.
Данное тождество согласует интегральные переносы в двух направлениях.
Оно не доказывает детальный баланс всей нелинейной модели и не требует
сохранения интеграла, уходящего за пределы конечного окна. Обе матрицы
явно учитывают такие потери через суммы строк меньше единицы.

Проверка должна соответствовать смыслу неизвестных: для `dense` и
`sparse_plan` проверяются узловая поддержка и сумма коэффициентов,
а для `conservative_pair` — пересечения ячеек, их ширины и взвешенная
сопряжённость. Неотрицательность и отсутствие переноса между непересекающимися
областями проверяются в обоих случаях. Кусочно-постоянный консервативный
перенос не является точным ускорением линейной интерполяции: это отдельная
численная аппроксимация, которую сопоставляют при уточнении энергетической
сетки в [плане верификации](@ref theory-validation).

## [Два способа вложения соседей](@id eq-embedding)

Исключение внешних степеней свободы заменяет их собственной энергией
вложения. В варианте `full_cell_resolvent` используется обратная связь через
полную центральную функцию Грина:

```math
\Sigma^x_{emb,+}=T_+\mathcal S_{+E_p}G^xT_+^\dagger,\qquad
\Sigma^x_{emb,-}=T_-\mathcal S_{-E_p}G^xT_-^\dagger.
```

Это объявленное приближение. Полная функция ячейки, уже связанной с обоими
соседями, не является поверхностной функцией полуцепи с удалённой центральной
ячейкой. Поэтому данное замыкание нельзя считать точным описанием
бесконечной ближайшей связи.

Режим `finite_chain` строит конечную открытую цепочку и исключает левую и
правую части отдельно дополнениями Шура. Для левой рекурсии, например,

```math
 g^R_{j,L}=[E I-h_j-\Sigma^R_{sc,j}
 -T_{j,j-1}g^R_{j-1,L}T_{j-1,j}]^{-1}.
```

Меньшая и большая инжекции исключаются вместе с запаздывающей компонентой.
В ячейке ``j`` используется ``h_j=h_0-jE_pI`` и
``\Sigma_{sc,j}(E)=\Sigma_{sc,0}(E+jE_p)``. Применяется выбранный оператор
сдвига; смещение не округляется к узлу.

`embedding_periods` задаёт число соседей **с каждой стороны**. Рекурсия
точна для объявленной конечной блочной цепочки с локальной собственной
энергией рассеяния. Бесконечная структура требует предельного исследования
по длине цепочки и энергетическому окну. Сингулярная неуширенная система
не исправляется скрытым ``i\eta``.

Независимая функция `finite_chain_green` возвращает также полные матрицы для
малых эталонов. Оба потока через границы сохраняются по отдельности и
проверяются в [балансе тока](@ref theory-observables). Полнооконные функции
из [главы о локализации](@ref theory-basis) не отменяют отсутствия
межъячеечной собственной энергии рассеяния в текущем транспортном замыкании.
