# [17. От физической структуры к вычисляемому состоянию](@id implementation-plan)

Зависимости физических величин задают естественный порядок построения.
Сначала геометрия определяет материалы, затем гамильтониан и базис,
далее матричные элементы рассеяния. Только после этого замыкаются
уравнения спектра, заполнения и поля. Таблица связывает полученные в
предыдущих главах формулы с публичными процедурами. Это карта расчёта и независимой верификации.

| Этап | Публичная функция | Выход и структура | Обязательный критерий |
|---:|---|---|---|
| 1 | [`reference_parameters`](@ref), [`ScaleSystem`](@ref) | структуры с размерностями | Unitful отклоняет неверные размерности; ``E_p/E_0=0.56`` |
| 2 | [`build_grids`](@ref), [`build_profiles`](@ref) | вещественные векторы, веса, маска доверия | ячейки слоёв; точная сумма доноров |
| 3 | [`build_bdd_hamiltonian`](@ref) | плотное хранение вещественной симметричной трёхдиагональной матрицы ``N_z^2`` | аналитический спектр ящика |
| 4 | [`build_localized_basis`](@ref) | плотные комплексные ``\Phi,\chi,H_0,Z,M^{-1},T_\pm`` | диагностика собственного уравнения, ортогональности и переноса |
| 5 | [`build_kernels`](@ref) | нормированные полные шестиосевые тензоры и `qᴷ` | составная эрмитовость/положительная полуопределённость; восстановление масштаба |
| 6 | [`retarded_green`](@ref), [`keldysh_green`](@ref) | полные массивы ``(E,k,a,b)`` | скалярный лоренциан и тождества |
| 7 | [`solve_scba`](@ref) | согласованная неподвижная точка до смешивания | все внутренние невязки (residuals), поточечные следы |
| 8 | [`solve_periodic_poisson`](@ref) | полное плотное окаймлённое решение | изготовленное решение, нейтральность, калибровка |
| 9 | [`solve`](@ref) | `NEGFSolution` | итоговый незапаздывающий SCBA и независимая верификация Пуассона |

## Внутренний вызов

1. `build_problem` выполняет только статический граф и вызывает
   [`validate_problem`](@ref).
2. Для заданного ``u_H`` `project_hamiltonians` формирует все полные блоки
   ``h_m``.
3. `solve_scba` строит **одну общую** тройку ``(G^R,G^<,G^>)`` и из неё все
   кандидаты рассеяния и вложения.
4. При выполнении критериев возвращается текущее согласованное состояние;
   иначе все компоненты одновременно смешиваются одним ``\alpha_\Sigma``.
5. `solve` реконструирует ``n_g``, решает окаймлённую систему Пуассона и смешивает
   ``u_H`` одним ``\alpha_P``.
6. После внешней приёмки выполняется финальный SCBA при сохранённом ``u_H``;
   [`validate_solution`](@ref) повторяет отображение Пуассона и балансы.

Достижение защитного ограничения возвращает `:max_iterations` или
`:max_poisson_iterations`; исключение физически недопустимой функции Грина или
кандидата возвращает явный статус отказа. Ни один такой статус не преобразуется в `:converged`.
Отдельно разрешённая подтверждённая приближённая приёмка возвращает
`:approximate` с предупреждением и может продолжить внешний цикл;
её условия заданы в [политике качества](@ref convergence-policy).

## Минимальный порядок запуска

```julia
using QCLNEGF

problem = build_problem(
    physical=reference_parameters(),
    numerical=tutorial_numerics(),
    scattering=ScatteringOptions(LO=false, acoustic=true,
        impurity=false, IFR=false, alloy=false),
)
solution = solve(problem; options=tutorial_options())
solution.status
```

Это быстрая сквозная проверка (smoke test) уравнений, а не количественный
результат reference design. Итоговый расчёт восстанавливает [`baseline_numerics`](@ref),
все каналы базового набора и серии ``k_{max}``, ``\Delta E``, ``N_b``, окна
базиса, ``N_\varphi,N_{q_z}``.

## Что смотреть по каждому критерию

| Критерий | Отладочный рисунок/таблица | Итоговый рисунок |
|---|---|---|
| профили/базис | ячейки, сумма доноров, ``s_i(S)``, центры/разбросы | [`plot_band_profile`](https://github.com/AfonenkoA/QCLNEGFRunner.jl/blob/main/docs/src/api/public.md) |
| ядра | срезы модуля/фазы и собственные значения составной матрицы | сравнение механизмов |
| Дайсон | ошибка лоренциана, ``\kappa_2(D)`` | [`plot_conditioning`](https://github.com/AfonenkoA/QCLNEGFRunner.jl/blob/main/docs/src/api/public.md) |
| SCBA | каждая невязка, ``\lambda,J,p_a`` по ``\nu`` | [`plot_convergence`](https://github.com/AfonenkoA/QCLNEGFRunner.jl/blob/main/docs/src/api/public.md) |
| Пуассон | ``r_P,r_U,r_n,\zeta,J,p_a`` по ``\mu`` | профиль зон/Хартри |
| спектр | отрицательные минимумы и доли краёв | [`plot_spectral_map`](https://github.com/AfonenkoA/QCLNEGFRunner.jl/blob/main/docs/src/api/public.md) |
| перенос | поточечные мнимые следы, два необработанных потока | [`plot_current_spectrum`](https://github.com/AfonenkoA/QCLNEGFRunner.jl/blob/main/docs/src/api/public.md) |
| приёмка | таблица столкновений, энергетического баланса и правила сумм | приложение о валидации |

Логарифмическая шкала всегда дополняется линейной проверкой знака. Комплексные
объекты показываются как вещественная/мнимая части либо модуль/фаза; тепловая
карта одной вещественной части не считается полной проверкой.

## Межъязыковая сверка

Порядок осей численных массивов — `(E,k,a,b)` и `(k,kprime,a,c,d,b)`, индексация
Julia/Wolfram начинается с единицы. Сначала сравниваются `h`, `T±`, `Khat/qK`,
затем одна свёртка SCBA, `Σ`, `G`, `n`, `Uᴴ`; только после этого — ток.
Допуски задаются отдельно для алгебраической ошибки округления и несошедшейся
неподвижной точки.

## Пространственная демонстрация перед транспортом

[Демонстрация локализации](@ref localization-demonstration) выполняет
первые стадии для реальной последовательности QCL и показывает, как
диагонализация, проекция и пространственное обрезание меняют представление.
Она позволяет проверить геометрию и операторы без ожидания многократного
цикла SCBA. [Физический атлас](@ref physical-atlas) дополняет её примерами
Пуассона, спектральной функции и кинематических факторов рассеяния.

Отдельный операторный опыт особенно полезен при локализации ошибки:
если матрица перекрытия или дисперсия уже неверны до рассеяния, изменение
смешивания SCBA не исправит исходную задачу. Если статические операторы
прошли проверку, следующий опыт сравнивает один несмешанный кандидат
собственной энергии, затем полный цикл и только после этого внешний
Пуассон. Такой порядок удерживает причинную связь между изменением и
наблюдаемым результатом.
