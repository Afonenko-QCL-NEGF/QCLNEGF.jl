# [11. Наблюдаемые и балансы](@id theory-observables)

Наблюдаемая величина получается из состояния после интегрирования по
энергии и импульсу, а не из номера последней итерации. Полезно различать
диагональную населённость выбранного базиса, координатную плотность,
поток частиц и электрический ток: у них разные размерности и, для тока,
разные соглашения о знаке. В формулах этой главы ``G,\Sigma,E,w``
обозначают физические величины; внутренняя реализация восстанавливает
единицы через [масштабы](@ref theory-scaling).

## [EQ-POP-001 — листовая матрица плотности](@id eq-sheet-density)

Интегрированная матрица плотности имеет размерность числа электронов на
площадь. Её диагональ даёт населённости базисных функций, а
внедиагональные элементы — когерентности:


```math
P_{ab}=-ig_s\sum_{em}w_m^{(k)}\frac{w_e^{(E)}}{2\pi}G^<_{emab},
\qquad \operatorname{Tr}P=N_D^{2D}.
```

При унитарной смене базиса отдельные диагональные населённости меняются,
но след остаётся инвариантным. Поэтому сравнение населённостей двух
локализаций требует согласования физических состояний, например по
перекрытию, а не только по номеру столбца.
Реализация: [`sheet_density_matrix`](@ref), [`state_populations`](@ref).

## [EQ-CURRENT-001 — исходящий поток](@id eq-boundary-flux)

Поток через правую границу определяется разностью выхода и обратной
инжекции. Оба слагаемых могут быть значительно больше их разности,
поэтому баланс двух границ — существенная проверка точности:

```math
\Phi_{out,+}=\frac{g_s}{\hbar}\sum_{em}\frac{w_e^{(E)}}{2\pi}w_m^{(k)}
\operatorname{Tr}[\Sigma^>_{emb,+}G^<-
\Sigma^<_{emb,+}G^>].
```

``J_{ef,+}=e\Phi_{out,+}`` положителен для движения электронов в ``+z``;
обычный ток заряда имеет противоположный знак. Реализация:
[`boundary_flux`](@ref), [`energy_resolved_current`](@ref),
[`bond_current`](@ref).

## [EQ-CURRENT-002 — энергетически разрешённый ток и ток через связь](@id eq-resolved-current)

```math
j_+(E_e)=\frac{eg_s}{\hbar}\sum_mw_m^{(k)}
\operatorname{Re}\operatorname{Tr}
[\Sigma^>_{emb,+}G^<-\Sigma^<_{emb,+}G^>],
```

а `bond_current` реконструирует выбранный ``G^<_{g+1,g}`` во всём локальном
базисе ячейки и вычисляет ``2\operatorname{Re}[H_{g,g+1}G^<_{g+1,g}]``.

## [EQ-COLLISION-001 — баланс частиц](@id eq-collision-balance)

Внутренний механизм перераспределяет электроны, но не создаёт их.
Поэтому после интегрирования приток и отток должны взаимно уничтожиться.
Для каждого внутреннего механизма

```math
C_s=\Re\operatorname{Tr}[\Sigma_s^<G^>-\Sigma_s^>G^<],
\qquad \mathcal R_s\propto\sum_{em}C_s=0.
```

## [EQ-POWER-001 — энергетический баланс](@id eq-power-balance)

В отличие от числа частиц электронная энергия может уходить в фононный
термостат. За один период электрическое поле сообщает движущемуся
электрону энергию ``E_p``. Стационарность требует, чтобы работа поля
компенсировалась энергией, отданной окружающей среде. В принятом знаке
``\mathcal P_{s\to e}`` обозначает мощность, получаемую электронами:


```math
\sum_s\mathcal P_{s\to e}+\Phi_{out,+}E_p=0.
```

Реализация: [`collision_balance`](@ref), [`power_balance`](@ref).

## [EQ-LEVELS-001 — диагностические уровни и диполи](@id eq-effective-levels)

Собственные векторы статического эффективного гамильтониана при ``k=0``
дают удобную диаграмму уровней. Координатный матричный элемент определяет
электрический диполь перехода. В физических единицах для ``E_j>E_i``
безразмерная сила осциллятора равна

```math
H(0;U_H)V=V\operatorname{diag}(E_i),\qquad
z^{eff}=V^\dagger ZV,\qquad
f_{ij}=\frac{2m_{ref}(E_j-E_i)|z^{eff}_{ij}|^2}{\hbar^2}.
```

[`effective_levels`](@ref) выполняет эту операцию только как последующую
обработку; она не заменяет пики полной спектральной функции и не является
моделью усиления.

## Как читать совместные графики

Сдвиг спектрального пика вместе с изменением поля Хартри указывает на
электростатическую обратную связь. Изменение ширины пика при почти неизменном
потенциале связано прежде всего с мнимой собственной энергией. Изменение
населённости без большого сдвига спектра отражает перераспределение
электронов между уже существующими состояниями. Различить эти процессы
помогают совместные карты спектра и занятого веса из
[главы 7](@ref theory-greens).

Сумма столкновительных вкладов может случайно оказаться малой при больших
ошибках отдельных механизмов. Поэтому таблица должна содержать каждый
канал, два исходных граничных потока, их разность и энергетический баланс.
Для цепочки с локальными вершинами график тока по координате дополнительно
проверяет отсутствие искусственных источников заряда. Связь этих проверок
с итоговым статусом изложена в [главе 12](@ref theory-validation).
